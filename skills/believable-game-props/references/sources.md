# Source register

These links were used for documentation or construction evidence. Product photos, materials and dimensions describe the named examples, not the unseen project. Modeling, distance and prioritization advice is a heuristic unless tied to a cited behavior or a measured project result.

## Skill and Blender

- [OpenAI Codex skills](https://developers.openai.com/codex/skills/) and [Agent Skills specification](https://agentskills.io/specification) — repository discovery under .agents/skills, required frontmatter, naming, and reference layout.
- [OpenAI skill eval guidance](https://developers.openai.com/blog/eval-skills) — test behavior on realistic tasks and distinguish triggering from behavior after the instructions are loaded.
- [Blender Workbench](https://docs.blender.org/manual/en/5.1/render/workbench/introduction.html) — studio lighting and cavity diagnostics. [Bevel](https://docs.blender.org/manual/en/5.1/modeling/modifiers/generate/bevel.html) and [Editing Normals](https://docs.blender.org/manual/en/5.1/modeling/meshes/editing/mesh/normals.html) — edge geometry, hardening and custom normals. [Weighted Normal](https://docs.blender.org/manual/en/4.0/modeling/modifiers/modify/weighted_normal.html) — area/angle weighting and preserved sharp edges. Match UI instructions to the installed version.
- [Blender Editing UVs](https://docs.blender.org/manual/id/5.1/modeling/meshes/uv/editing.html) — scale and packing operations. [Normal Map](https://docs.blender.org/manual/en/latest/render/shader_nodes/displacement/normal_map.html) — matching UVs, non-color data and documented Blender tangent convention. [Principled BSDF](https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/principled.html) — preview material controls, including coat and sheen. None guarantees engine parity.

## Engine and performance

- [Google Filament materials](https://google.github.io/filament/main/materials.html) — separates dielectric, metallic, coat and cloth response in a real-time implementation. [Unity texture types](https://docs.unity.com/en-us/engine/6000.7/manual/materials-and-shaders/textures/textures-getting-started/texture-types) — using normals for apparent detail without more polygons. Neither defines a GTA material binding.
- [Cfx creating GTA V assets in Blender](https://docs.fivem.net/docs/assets-manual/beginner-series/part-3/) — illustrative shader selection, drawable and archetype setup, CodeWalker-era export. [Sollumz shader setup](https://github.com/Sollumz/wiki/blob/main/tutorials/creating-props/setting-up-sollumz-shaders.md) — example without alpha, named diffuse/normal/specular samplers, and the Blender normal-map color-space note.
- [Sollumz releases](https://github.com/Sollumz/Sollumz/releases) — 2.8.0 introduces a native Gen8/Gen9 path through optional PyMateria. [Versioned Drawable docs](https://docs.sollumz.org/2.6/documentation/drawables.ydr) — shader and texture dictionaries, geometry hierarchy, LODs. [Cfx resource manifest](https://docs.fivem.net/docs/scripting-reference/resource-manifest/) and [data files](https://docs.fivem.net/docs/game-references/data-files/) — resource mounting and archetype data support. [Cfx Legacy vs. Enhanced](https://docs.fivem.net/docs/developers/legacy-vs-enhanced/) — build-specific differences. Check the installed build, not only these examples.
- [Epic real-time rendering guidance](https://dev.epicgames.com/documentation/unreal-engine/guidelines-for-optimizing-rendering-for-real-time-in-unreal-engine) — relationship between meshes, material IDs and draw cost. [Mesh LOD](https://dev.epicgames.com/documentation/en-us/unreal-engine/static-mesh-automatic-lod-generation-in-unreal-engine) and [Texture Streaming](https://dev.epicgames.com/documentation/en-us/unreal-engine/texture-streaming-overview-for-unreal-engine) — screen coverage, LOD and mip/streaming examples. Use the principles, not those engine settings or example budgets, in another target.
